
# CineVerse - A Netflix-Inspired Movie Streaming App

CineVerse is a modern, professional, and feature-rich movie streaming mobile application built with Flutter. It is designed to provide a premium user experience similar to popular streaming services like Netflix and Amazon Prime Video. The app features a dark, elegant UI with neon accents, smooth animations, and a user-friendly layout.

## Features

*   **Modern UI:** A dark, elegant, and cinematic user interface inspired by Netflix.
*   **Smooth Animations:** Seamless transitions and micro-interactions for a delightful user experience.
*   **Movie Discovery:** Browse popular, top-rated, now playing, and upcoming movies.
*   **Detailed Information:** View detailed information about each movie, including the cast, crew, and similar movies.
*   **Watch Trailers:** Watch movie trailers directly within the app.
*   **Search:** Easily search for your favorite movies.
*   **Watchlist:** Save movies to your watchlist.
*   **User Profile:** A dedicated profile page for each user.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Flutter SDK: [https://flutter.dev/docs/get-started/install](https://flutter.dev/docs/get-started/install)

### Installation

1.  Clone the repo

```sh
git clone https://github.com/your_username_/CineVerse.git
```

2.  Install packages

```sh
flutter pub get
```

3.  Run the app

```sh
flutter run
```
